# 🕷️ Spider-Verse Project

This is the repository for the Spider-Verse project, developed as part of my studies. It is an interactive application inspired by the Spider-Man universe, built with modern front-end technologies such as React, Next.js 13, Framer Motion, Sass, and TypeScript to deliver a visually engaging and high-performance experience.

---

## 💻 Technologies Used

- [React.js](https://reactjs.org) (v18)  
- [Next.js](https://nextjs.org) (v13)  
- [TypeScript](https://www.typescriptlang.org) (v5)  
- [ESLint](https://eslint.org)  
- [Framer Motion](https://www.framer.com/api/motion)  
- [SASS](https://sass-lang.com)

---

## 🌿 Branches

- main – Final version with all features implemented
- template – Starter structure with assets, libraries, folder organization, and ESLint configuration
- live – Partial version with the project base prepared for implementing animations and interactivity
